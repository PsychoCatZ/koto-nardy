КотоНарды — 3D-нарды в стилистике КотоИмперии
================================================

Запуск: KotoNardy.exe

При первом запуске Windows может показать синий экран
«Windows защитила ваш компьютер» — это стандартное предупреждение
SmartScreen для неподписанных программ.
Нажмите «Подробнее» → «Выполнить в любом случае».

Сохранения партий, настройки и статистика хранятся локально
в профиле пользователя (LocalStorage приложения).

Управление:
  - ЛКМ по фишке — выбрать, по подсветке — ходить
  - Фишку также можно перетащить мышкой
  - ПКМ / колесо — вращение и масштаб камеры
