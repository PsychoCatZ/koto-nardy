КотоНарды — настольное приложение
=================================

Это Electron-обёртка поверх продакшен-билда Vite.

Сборка:
  1. npm install                 (в папке desktop)
  2. Соберите веб-билд из корня проекта: npm run build
  3. Скопируйте папку dist в desktop/app
  4. Создание пакетов:
     - Windows x64: npm run dist:win    (нужен wine64 для rcedit)
     - Linux x64:   npm run dist:linux

Запуск без упаковки: npm start (требует папку desktop/app с билдом)

Примечание: Windows SmartScreen может пометить неподписанный exe —
это нормально для локальной сборки, выберите «Подробнее» → «Выполнить в любом случае».
