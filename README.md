# КотоНарды (KotoNardy)

3D-нарды в браузере: длинные и короткие, игра против ИИ или с другом на одном экране.
React + TypeScript + Three.js, без бэкенда — всё работает локально в браузере.

## Возможности

- **Два варианта игры** — длинные нарды (все 15 фишек с головы, круговой маршрут) и короткие нарды.
- **Игра против ИИ** — три уровня: «Котёнок», «Кот», «Бешеный кот».
- **Локальный режим** — два игрока за одним экраном, камера поворачивается к текущему игроку.
- **Правила по официальному регламенту РФ** (приказ Минспорта № 347 от 30.04.2025):
  - правило шести — запрет закрытия шести точек подряд, пока все 15 фишек соперника находятся до блока (по линейному прогрессу, а не по круговой доске);
  - правило большего числа — если доступна только одна кость, играется большая;
  - снятие только по точному числу: точка № 1 дома снимается единицей, № 6 — шестёркой; пока не все 15 фишек вошли в дом, снимать нельзя;
  - проверка блока на каждом промежуточном шаге хода.
- **Два профиля счёта** (переключаются в настройках):
  - *официальный РФ* — оин = 1 очко, марс = 2 очка;
  - *классический* — оин = 1, марс = 2, кокс = 3 (фишка соперника в стартовой четверти), домашний марс = 4 (все 15 в доме, 0 снято). Приоритет: кокс → домашний → марс → оин.
- **3D-доска** — свободный обзор камерой, анимации бросков кубиков и ходов, подсветка допустимых ходов.
- **Удобства** — отмена хода (Undo), автосохранение партии, турнирный счёт (очки + марсы), панель отладки для разбора позиций.

## Быстрый старт

```bash
npm install
npm run dev        # дев-сервер на http://localhost:3000
```

## Скрипты

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Дев-сервер с hot reload |
| `npm run build` | Прод-сборка в `dist/` |
| `npm run preview` | Локальный просмотр сборки |
| `npm test` | Тесты игровой логики (vitest, 32 теста) |
| `npm run lint` | Проверка ESLint |

## Структура проекта

```
src/
├── game/            Игровой движок (не зависит от UI и 3D)
│   ├── engine.ts        генерация последовательностей ходов, ход игры
│   ├── rules/           правила: long.ts (длинные нарды), short.ts (короткие)
│   ├── ai.ts            оценка позиций и выбор хода ИИ
│   ├── controller.ts    связка движка, 3D-сцены и UI
│   └── tests/           unit-тесты правил и дымовой тест
├── three/           3D-сцена: доска, фишки, кубики, анимации, пикинг
└── ui/              React-интерфейс: меню, HUD, настройки, оверлей победы
desktop/             Обёртка Electron для сборки десктопного дистрибутива
```

Игровая логика (`src/game/`) написана чисто и покрыта тестами отдельно от рендеринга — правила можно переиспользовать в любом другом интерфейсе.

## Десктопная сборка (Windows 11 x64, Electron)

В папке `desktop/` — готовая обёртка Electron (собственная схема `app://`, так что ES-модули работают из локальных файлов без сервера).

```bash
cd desktop
npm install
npm run package:win   # готовый KotoNardy-win32-x64 появится в desktop/out/
```
